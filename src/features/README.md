# Features

Feature-based modules. Each feature owns its own `components/`, `pages/`,
`hooks/`, `types/`, `services/`, and `api/` directories.

Scaffolded modules:

- employees, teams, departments, projects
- github, jira, clickup, excel-upload
- ai-engine, analytics, dashboard, reports, notifications
- settings, organization, audit-logs, administration

This prompt establishes the enterprise foundation only. Future prompts add
business logic per module.
